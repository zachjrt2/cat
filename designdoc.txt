Cozy Cat Sanctuary
Game Design Document v1.0

Genre: Cozy Idle / Collection / Virtual Pet
Platform: Web (Mobile First)
Deployment: GitHub Pages (Static Website)
Engine: Phaser 3 + TypeScript + Vite
Monetization: None (initially)
Target Session Length: 1–10 minutes
Audience: Cozy gamers, cat lovers, idle game players

The chosen asset pack is particularly well-suited because it already includes multiple cat animations, nearly 50+ color variations, and separate pattern overlays that can be mixed and matched to create a large population of unique cats without requiring additional artwork.

Vision Statement

Create a relaxing digital cat sanctuary where players collect, care for, and observe dozens of unique cats.

The primary reward is not progression.

The primary reward is attachment.

Players should gradually learn:

Which cats are friends
Which cats are troublemakers
Which cats sleep all day
Which cats constantly demand attention

The game should feel alive even when the player does nothing.

Watching the sanctuary should be enjoyable.

Core Pillars
1. Low Stress

No fail states.

No dead cats.

No punishment.

Ignoring a cat for a day simply means it is slightly less happy.

2. Personality First

Every cat should feel different.

Players should eventually refer to cats by name instead of color.

3. Watching Is Gameplay

The sanctuary should remain entertaining even when the player is idle.

Cats should:

Wander
Sleep
Play
Follow friends
Chase toys
Groom themselves
Sit together
4. Collection Without Pressure

Collecting cats is exciting.

Missing cats is not frustrating.

Animation Usage

The asset pack includes multiple states such as sitting, looking around, laying down, walking, running, and additional playful movement animations. These can be mapped directly to cat behaviors.

Sit	Idle
Look Around	Curious
Lay Down	Relax
Sleep	Recover Energy
Walk	Wander
Run	Zoomies
Play	Toy Interaction
